# Web Agent ZM

Windows 本机网页自动化工作台。通过自然语言指挥 Playwright 浏览器访问网站、搜索、点击和输入；通过自然语言录入账号密码并自动关联登录步骤，再完成查询与导出。

## 当前交付：自然语言登录与凭据自动保存

- 启动空白浏览器，手动指令可跨 HTTP/HTTPS 网站访问、搜索、点击和输入。
- 登录作为流程步骤，账号和密码由 Windows 当前用户 DPAPI 加密保存；允许复用当前已登录会话。
- 兼容 OpenAI Chat Completions 的工具调用，一条指令执行后等待下一条。
- 网页内实时画面、文字反馈和模型请求次数。
- 批次号等参数文件命名、下载完成且非空校验、网页下载入口。
- 浏览器执行互斥；指令忙碌时拒绝第二条指令或关闭浏览器。
- 本地模拟内部系统，支持查询、暂无数据和 CSV 导出。

- 成功动作录制、参数建议与用户确认编辑器。
- SQLite 流程持久化、不可覆盖的历史版本、单次确定性回放。
- 条件分支支持“暂无数据”结束运行；回放不调用 LLM。

- 参数表格填写/粘贴、串行队列、步骤边界暂停/继续/停止。
- 任务历史、逐行结果和文件关联持久化，重启后可查看和下载。

- 登录过期程序恢复、完成证据检查、每失败步骤最多两次 LLM 定位恢复。
- 任务临时修复记录、人工审核后原子新增流程版本、真实恢复调用统计。

- 流程/任务/文件确认删除、文件本地回收和关联保护。
- 配置诊断、任务总耗时/模型耗时、重启中断和连接退出加固。

**待接入验收**：用户真实内部管理系统；当前按用户选择先完成通用加固。这些按后续阶段单独实施，不包含在当前版本。

## 安装与启动（PowerShell）

需要 Python 3.11+、Node.js 22+、Git。已在 Windows / Python 3.14 / Node.js 24 验证。

```powershell
git clone -b explicit-login-step2 https://github.com/Sora-Ava/web_agent_ZM.git
cd web_agent_ZM
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.lock
.\.venv\Scripts\python.exe -m pip install -e ./backend --no-deps
.\.venv\Scripts\python.exe -m playwright install chromium
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
Copy-Item .env.example .env
```

编辑 `.env` 中的模型配置后启动；已有 `.env` 时不要重复覆盖：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start.ps1
```

打开 <http://127.0.0.1:8000>。终端按 Ctrl+C 退出。点击“启动浏览器”会打开独立 Chromium 窗口，工作台保留实时预览。手动操作前点击“人工接管”，等待显示“人工接管中”，完成后点击“交还 Agent”。当前操作会先结束，后续自动步骤等待交还；人工操作不会自动录制。原生窗口无法阻止用户点击，Agent 执行期间请避免手动操作。交还后会重新观察页面、清除模型旧上下文与已验证账号记录，因为人工操作可能切换账号；后续流程通过已确认的成功标识判断会话可用，不校验当前账号身份。`HEADLESS` 控制直接调用底层执行器的默认方式，工作台新启动始终显示窗口。

Windows 也可双击 `scripts/start.cmd` 启动。启动脚本检查 `.env`、Python 依赖和前端构建；端口已有本项目服务时复用并打开页面，其他服务占用时提示处理。服务就绪后自动打开默认浏览器。使用 `scripts/start.ps1 -NoBrowser` 可只启动服务。关闭终端会结束服务，未完成任务下次启动标记中断，不会自动续跑。

顶部“环境检查”显示浏览器安装、登录/模型/查询等待配置就绪状态、导出与回收目录和超时；不连接模型、不显示密钥。诊断仅检查配置完整性，真实页面定位仍须实际验收。

## 删除管理

- 标准流程旁的删除按钮归档全部版本，不能再启动或编辑；既有任务使用的版本快照和文件保留。有未结束任务时，须先停止任务。
- 任务历史支持列表和详情删除，仅可删除已完成/失败/停止/中断任务，参数行、步骤和修复记录一起移除。文件保留并解除任务关联，仍可在导出文件列表下载。
- 导出文件删除后移入配置导出目录下 `.trash`，不会永久删除。列表移除，关联历史显示“已移至回收目录”；可从本地回收目录手动取回。取回的文件不会自动重新登记到工具，仍可在本地直接使用。

三类删除都要求确认。执行或暂停中的文件不能删除；回收目录越界、存在同名文件或文件被占用时不覆盖、不丢失登记。任务历史删除不可在界面撤销，数据库备份可用于人工恢复。

## 通用浏览器使用

1. 点击“启动浏览器”，首次启动停留 `about:blank`，不会读取账号密码自动登录。
2. 输入 `访问 www.baidu.com 并搜索今日黄金价格`。Agent 分步导航、识别搜索框、填写并点击搜索或按 Enter。
3. 完成后停留结果页面，显示文字反馈和实时画面。也可分别发送“访问网址”“填写搜索框”“搜索”等指令。

手动指令支持跨站 HTTP/HTTPS；不支持 file、data、javascript、浏览器设置地址或 URL 内嵌账号密码。模型仅接收脱敏页面文字/元素，不发送截图或输入框当前值。无名称输入框可使用观察中提供的唯一 ID 定位。页面访问受本机网络和网站验证机制影响。

本步只操作当前标签页，不支持切换标签页，也不自动阅读网页生成来源摘要。账号密码可按下方限定语法自然语言录入；程序在请求模型前提取原值，模型只选择目标字段。

标准流程只绑定一个 HTTP(S) 来源。首个成功操作或登录绑定草稿来源；切换网站需点击“新建录制”。不同来源可以分别保存流程，不依赖全局固定网址。跨来源业务暂不支持固化。

本机提供 /demo/login 演示系统。按下方配置 demo_local 凭据和登录定位即可录制；批次号 NONE 可验证“暂无数据”。自然语言指令需要配置模型，程序登录和正常回放不调用模型。

## 自然语言登录与自动录制

1. 打开登录网址，分别发送 `账号 "operator"`、`密码 "demo-password"`，再发送 `点击登录`；也可在同一条指令中明确账号、密码并追加点击登录。
2. 含空格或分隔符的值使用完整引号。值含双引号时可用 `密码 「含双引号的值」`；反斜杠按字面处理，不使用 JSON 转义规则。
3. 凭据填写成功后自动用 Windows 当前用户 DPAPI 加密保存，不写入或覆盖 `.env`。填写后保存失败会明确显示“已填写但未保存”，不会自动重填。
4. 提交后的反馈为“结果待确认”。点击“保存为标准流程”，选择当前页面唯一可见的业务标识，勾选确认；仍有可见密码框或标识不唯一时不能编译登录步骤。
5. 继续录制查询与导出，再检查并保存完整流程。登录网址和本机凭据引用自动关联，无需手工配置引用。正常单次和批量回放零模型调用，重启后可继续使用。

人工接管输入不自动录制；不支持验证码、跨站 SSO、多标签或分段认证。短账号也可录入，协议名称/字段类型与实际凭据数据分别处理。[合成验收记录](docs/natural-login-validation.md)说明测试范围和限制。

## 可选的 .env 凭据与显式登录

在 .env 添加命名凭据集合；示例仅用于本机演示，实际账号密码由用户自行配置：

```dotenv
CREDENTIALS_JSON='{"demo_local":{"origin":"http://127.0.0.1:8000","username":"operator","password":"demo-password"}}'
```

修改后重启服务。界面只能查看凭据名称、允许来源和是否就绪。密码不进入模型、流程、任务参数、日志或文件名。原 SITE_URL/SITE_USERNAME/SITE_PASSWORD 和全局登录定位不再用于登录。

1. 点击“启动浏览器”，再点击“配置并执行登录”。
2. 填写登录网址，选择凭据引用，填写账号框、密码框、提交按钮、成功标识的唯一定位。演示系统分别为 #username、#password、#login、#logged-in，登录网址为 http://127.0.0.1:8000/demo/login。
3. 点击“执行登录”，成功后录制一个登录组合步骤。可直接保存为独立登录流程，也可继续指挥查询和导出。
4. “保存为标准流程”后检查步骤和参数；登录网址和凭据引用会成为可变参数。密码只在执行时注入。
5. 编辑器可添加登录步骤，或从同来源已有流程复制登录配置；关联参数生成独立标识，源流程修改不会影响复制结果。

登录要求实际页面、流程和凭据的来源（协议、主机、端口）一致。跨来源跳转会被拒绝。勾选“允许复用当前已登录会话”后，只要同来源的成功标识唯一可见，即允许使用当前账号会话，不要求与录制账号相同。后续查询导出使用当前账号；如需指定账号，请关闭浏览器后重新启动或明确强制登录，不会自动猜测退出入口。

## 保存并运行标准流程

从侧栏选择流程，填写本次参数并运行，或使用参数表格批量执行。只有流程中存在登录步骤才会登录；不含登录步骤的流程直接执行网页操作，不补做认证。

业务输入参数保留前导零；网址参数限流程来源，凭据参数使用下拉选择本机引用。导出文件名包含流程名和普通业务参数，加唯一标识；排除网址和凭据参数。

每次编辑新增版本，旧版本不可覆盖。新格式数据默认保存在 data/agent-v2.sqlite3；可通过 DATABASE_PATH 指定新库。非正式系统不提供旧配置导入、流程转换或旧格式兼容，原数据库和文件不会自动删除。不要将旧格式库设置为新版本 DATABASE_PATH。

## 批量任务与任务历史

选择标准流程后点击“批量运行”。可逐个填写表格单元格、添加/删除行，也可从 Excel 复制多行后粘贴：使用制表符分列，每行按参数列顺序排列，不含表头。点击“应用粘贴内容”会替换当前表格。批次号按字符串处理，保留前导零；必填/类型校验失败时整批不提交。每个任务最多 500 行。

点击“加入任务队列”时固定流程版本与全部参数。编排会话等待输入时不会插入队列任务，需要点击“结束编排并启动队列”。正常单次运行同样生成持久化任务，并结束编排；任务串行执行，每行重新进入流程入口。业务失败仅影响该行，后续行继续；总体“已完成”表示队列已处理完毕，仍需查看各行成功/无数据/失败计数。

从“任务历史”查看最近 50 个任务，展开每行步骤并下载关联文件。运行、排队中的任务可暂停/停止；暂停中的任务可继续。控制不会中断当前浏览器动作，而是在动作完成或超时后生效；暂停期间保留浏览器执行权，继续从下一未完成步骤开始，停止后保留已有文件并将后续行标记未执行。

流程、任务、行结果、步骤和文件登记保存在同一 SQLite 库。重启后任务不自动续跑，未完成任务标记已中断；文件列表恢复已登记文件，磁盘文件被外部删除时下载返回不存在。第二阶段以前未持久化登记的旧文件不会自动扫描导入，但磁盘文件保持原样。

定位变化和登录过期按下方有限恢复规则处理；完整真实系统全局故障加固仍在后续阶段。可在任务历史手动停止任务，超时配置仍由 `.env` 控制。

## 有限恢复与修复审核

正常标准流程仍然零模型调用。步骤失败后先检查本步骤完成证据：输入/选择值是否已到位，本次查询是否已更新，本步骤是否已有新增且非空文件。旧任务文件不算本次完成证据。导出已触发但下载结果不确定时，本行失败并提示人工检查，不再次点击导出。

检测到本流程登录页时，程序仅使用已执行的登录步骤重新登录，每行最多一次，再从入口重建当前行已完成的非下载步骤与查询条件；前缀包含导出时不重复回放，报告需人工检查。重新登录失败或浏览器不可用时当前任务失败，剩余行未执行，后续队列停止派发。修复浏览器/流程登录配置后，显式点击“重新启动队列”。

仍需定位恢复时，LLM 每个失败步骤最多请求两次，每次请求整体超时使用既有 MODEL_TIMEOUT_S 配置（默认 60 秒），不自动重试网络请求。只接收文字/元素、原步骤定位与错误；不发送截图或当前字段值。建议仅允许页面观察中的语义定位，原动作类型、查询参数、等待、条件规则和文件名不能改变。模型不可自报完成，所有恢复动作仍须通过程序执行与结果校验。未配置模型、建议不可用或两次均失败，则本行失败，下一行从入口重新开始。

成功定位修复仅在当前任务内复用，任务历史显示恢复请求数与步骤记录。任务结束后，在“待确认定位修复”检查原定位和建议，选择同一步骤的一个修复，勾选确认后保存为新版本。旧版本和任务快照保持不变；流程已出现更新版本时审核返回冲突，需要打开最新版手动编辑。

本阶段自动修复聚焦单个元素定位；条件歧义、导航 URL 变化、复杂交互或无法证明完成的业务变更仍需人工编辑。不含登录步骤的流程遇到认证问题会提示先运行登录流程或加入登录步骤，不隐式寻找其他登录依赖。恢复和程序重新登录都遵守暂停/停止边界，正在进行的请求/动作完成或超时后控制生效。

## 模型配置

```dotenv
LLM_BASE_URL=https://your-provider.example/v1
LLM_API_KEY="your-key"
LLM_MODEL=your-tool-capable-model
```

客户端向 `LLM_BASE_URL + /chat/completions` 发请求。不要把完整 `/chat/completions` 路径写进 base URL。服务及模型必须支持 `tools`、`tool_calls`、工具结果消息及 JSON Schema（包括 `$defs` 引用）；无法使用工具时会明确报错。

可先独立检查模型配置，不启动浏览器：

```powershell
.\.venv\Scripts\python.exe scripts/check_llm.py
.\.venv\Scripts\python.exe scripts/check_llm.py --tools
```

脚本只读取项目 `.env` 的 LLM 配置，分别检查文本响应与最小工具协议，不输出 API 密钥。

模型每条指令最多 8 轮，默认每次请求超时 60 秒，不自动重试 API 请求。动作失败直接反馈，首版不会自动恢复。模型产生的总结仅作为解释，程序记录的操作/下载结果才是成功证据。

## 接入真实系统

只在本地 `.env` 配置，不把凭据发到聊天或提交仓库：

| 配置 | 含义 |
| --- | --- |
| `CREDENTIALS_JSON` | 本机命名凭据集合，包含来源、账号和密码 |
| `LOADING_SELECTOR` | 查询加载遮罩 CSS 定位 |
| `RESULT_SELECTOR` | 查询结果容器 CSS 定位，查询后内部应发生 DOM 更新 |
| `DOWNLOAD_DIR` | 可选绝对导出目录，默认 `<repo>/downloads` |

带空格或 `#` 等字符的配置值请使用引号。修改配置后重启服务。首版操作主页面，尚不支持 iframe 内元素或多标签切换，跨源导航被拒绝；真实系统如使用这些结构，需要先适配。查询等待要求加载元素与结果容器存在，观察到加载出现再消失，且结果容器内容发生 DOM 更新；查询全程无加载提示或仅隐藏/显示相同结果的站点需要调整等待实现。真实站点的定位配置必须实际验证后使用，示例选择器并非通用选择器。

登录密码由程序直接填写，不传给模型。页面提取不包含密码/隐藏字段、输入框当前值、脚本或隐藏文本；模型请求全文再次过滤已配置凭据。只发送页面文本和元素信息，不发送截图。必要的业务页面文本仍会发送到你配置的 LLM 服务。

实时画面经本机 WebSocket 传给工作台，不上传到模型或外部服务。应用仅绑定 `127.0.0.1`，不应部署到公网。`.env`、导出文件和测试截图均被 Git 忽略。
